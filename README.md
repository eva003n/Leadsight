# Leadsight
Turn WhatsApp chats into structured leads with a web-based CRM dashboard. An intelligent WhatsApp bot that interacts with potential customers, collects their details (name, email, inquiry type), and automatically pipes this data into a secure web-based CRM dashboard for sales teams to follow up.
